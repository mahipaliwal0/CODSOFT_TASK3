# Task 3 - Secure Code Assessment

## Objective
Analyze a Python application for common security vulnerabilities.

## Security Issues Identified
- Hardcoded Password
- Plain Text Password
- No Input Validation
- Unlimited Login Attempts

## Recommended Fixes
- Password Hashing
- Input Validation
- Login Attempt Limitation
- Secure Coding Practices

## Tools Used
- Python
- VS Code
- Microsoft Word

## Outcome
The assessment demonstrates basic secure coding practices and vulnerability identification.
